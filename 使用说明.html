卡牌赛事编排 · 使用说明（v1.11.2）

一款纯本地离线的赛事编排 / 计时记分工具。支持瑞士轮、单败、双败、循环赛、小组赛，
可自由组合成多阶段赛程，局制与记分规则可按阶段分别设置。全部数据保存在本机，不联网、不上传。

二、五分钟上手

  1. 新建赛事：打开后点右上角「新建赛事」，填赛事名称。
  2. 导入选手：进入「选手管理」，在「批量导入选手」里每行一个名字粘贴，点导入； 也可用「从文件导入选手（txt/csv）」。可填种子序号与初始分。
  3. 定赛制：进入「赛事设置」，选定赛制、轮数、晋级条件；需要多阶段就点「添加阶段」。
  4. 跑比赛：进入「对阵与录入」，点「生成下一轮」→ 录入比分 → 「完成本轮」→ 再生成下一轮。
  5. 收尾：全部轮次结束后点「结束本阶段并晋级」；去「排名」看名次，去「导出」出 CSV / PDF / 存档。
顶部导航共五个页签：赛事设置、选手管理、对阵与录入、排名、导出；右上角「赛事列表」可管理多个赛事。

三、赛事设置详解

3.1 基本信息

赛事名称，以及当前所处阶段。所有设置都保存在这个赛事里，赛事之间互不影响。

3.2 局制（默认值，可被单个阶段覆盖）

参数含义
每场局数这一场最多打几局，例如 3 局
赢多少局获胜先赢到该局数即结束本场；填 0 表示「不论赢几局都打满全部局数」
记录每局比分开启后可录每局的具体小分（用于「按小分累加」计分）

例：3 局 / 2 胜 = 三局两胜；5 局 / 0 胜 = 必须打满 5 局，最后按总胜局判胜负。

3.3 记分规则（默认值，可被单个阶段覆盖）

五种计分模式，任选其一：

模式界面名称说明
大比分逐档按大比分逐档设分（列出所有可能比分分别设分）系统把该局制下所有可能的最终比分列成一张表，逐个填「胜方得 / 负方得」，见 3.3.1
胜负平按胜负平轮空积分（自定义分值）直接给胜 / 平 / 负 / 轮空各设一个分值，如 3 / 1 / 0 / 3
按赢局按赢下局数计分（每局分值）每赢一局得固定分，如每局 1 分；比分 2:1 则得 2 分
按小分按小分累加（需记录每局比分）逐局录入具体小分（如麻将的点数），按小分累加
自定义公式自定义公式（表达式）写表达式，可用变量：w 胜局、l 负局、d 平局、b 轮空、p 小分等，例 w*3 + d*1

3.3.1 按大比分逐档设分（最常用）

选择该模式后，系统会按当前局制自动列出全部可能比分，逐个填分值。以「3 局、先赢 2 局」为例：

最终比分胜方得负方得平局双方各得说明
2 : 030—胜者赢 2 局、负者赢 0 局
2 : 121—胜者赢 2 局、负者赢 1 局
  • 2:0 与 0:2 视为同一档，只列一次，不用重复填；
  • 局制换成「5 局、先赢 3 局」，表会自动变成 3:0 / 3:1 / 3:2 三行；
  • 局制设为「打满 N 局」且平局处理选「允许平局」时，会多出平局档（如打满 2 局有 1:1， 打满 4 局有 2:2），该行只需填「双方各得」；
  • 表下方的「兜底分值」用于：实际比分不在表内（例如中途改过局制）时按胜 / 平 / 负给分；
  • 录入时用「直接填比分」，系统会自动对上档位给分，卡片上会实时显示各档分值提示。

「未打完」档位（计时器到点 / 中途结束）

表的下半部分单独列出「未打完」的比分档，例如「3 局、先赢 2 局」有 1:1、1:0、0:0 三行。
比赛没打满就被收场（计时器到点、选手弃权、场地到点等）时，按这张表给分：

已打比分领先方得落后方得平分双方各得适用情形
1 : 1——1双方各赢 1 局就被叫停
1 : 020—一方 1:0 领先时被叫停
0 : 0——0一局都没打就收场（通常双方都不得分）
  • 未打完的比分不会混进上半部分的「最终比分」表，两者互不影响；
  • 如果某一档没单独设，「未打完」会先退回同一比分的档位，再退回胜 / 平 / 负兜底分值；
  • 赛制为「打满 N 局」时，未打完档位就是所有「合计局数 < N」的比分。
例：3 局 2 胜制的比赛打到 1:0 时场地到点，若「1:0 领先方得」填 2、「落后方得」填 0，
则领先者记 2 分、落后者记 0 分，这场按「未打完」计入双方战绩（胜 / 负各 1 场）。
典型用法：2:0 胜方 3 分、2:1 胜方 2 分负方 1 分；或 2:0 得 3 分、2:1 得 2 分，负方一律 0 分。

平局处理（在阶段设置里，淘汰类阶段尤其重要）：

  • 自动加赛决胜局（推荐）：打平则继续加局，直到分出胜负；
  • 允许平局：平局按平局分计入（不适用于淘汰赛）；
  • 由裁判手动指定晋级者。

3.4 排名依据（Tiebreaker）

积分相同时的排序依据，共 13 种，用每行右侧的「上 / 下」按钮调整优先级（越靠前越优先）：

依据含义
积分主排序
对手分总和 (Buchholz)所有对手的积分之和，赛程越强分越高
相互胜负关系 (H2H)两人直接交手谁赢过
净胜局数赢下的局数 − 输掉的局数
赢下局数总共赢了几局
输掉局数总共输了几局（越少越靠前）
胜场数赢了几场（不看平局）
累进分每轮结束时的积分再累加一遍 —— 越早赢越占优，专门用来区分「前期猛」和「后期追」
累计小分各局小分之和（需记录每局比分）
净小分本人累计小分 − 所有对手累计小分之和
上一阶段得分多阶段赛事里，该选手在上一阶段的最终积分（小组赛带分进淘汰赛时常用）
初始种子序种子号靠前者优先
手动指定你在排名表右侧手工调的名次

默认顺序：积分 → 对手分 → 相互战绩 → 净胜局 → 赢局 → 输局 → 胜场 → 累进分 → 累计小分 → 净小分 → 上阶段分 → 种子 → 手动

  • 旧赛事打开时会自动补齐新依据（插在「种子序」之前，不改变你原来的优先级）；
  • 排名表会按实际启用情况显示「累进分 / 净小分 / 上阶段分」列；
  • 不需要的依据可以删掉：每行右侧有「移除」按钮，删掉的依据立即失效， 下方「添加依据」下拉可以再把它加回来（加回时排在最末位，可再点「上」提权）；
  • 全部删光也允许 —— 此时同分选手保持录入顺序，不会再偷偷退回默认依据表；
  • 删除结果会随赛事一起保存，重新打开不会被回填；
  • 「手动指定」用于人工干预：在排名表最右侧点「上 / 下」直接调整该选手位置。

3.5 轮空规则（人数为奇数时）

轮空全部由系统自动判定，生成轮次时直接排好，并按「轮空分」自动计分，不需要你指定：

选项说明
自动：首轮随机，之后给最低分（默认）首轮随机，之后让积分最低者轮空，且每人最多轮空一次
自动：始终给当前积分最低者每轮都由当时积分最低者轮空
自动：每轮随机抽一人完全随机
自动排好后，我自己在「手动编排」里改系统先自动排好，不满意再去对阵页手动换人

轮空在排名中按「一场胜利」计算：轮空者的场次 +1、胜场 +1，同时另记一个「轮空次数」。
所以 7 人瑞士轮里轮空过一次的人，排名表上就是「4 场 3 胜」而不是「3 场 3 胜」，
按胜场数、胜率比较时不会被轮空吃亏。

3.6 比赛计时器（每场限时 + 到点自动结算）

「③ 赛事设置 → 比赛计时器」：

设置说明
启用每场限时打开后，对阵卡片上出现倒计时与开表按钮
每场限时（分钟）默认每场多少分钟。开表时写入该场，之后改这里不影响已在计时的场次
到点自动结算勾选 = 到点自动收场结算；不勾 = 到点只把倒计时标成反白闪烁，由裁判手动点结算
到点时双方局数相同①「记为平局」：双方按未打完档位里的平分行给分；②「种子号靠前者获胜」：种子小的一方赢；③「不结算，继续打」：只提醒，表继续走

对阵卡片上的计时器一行：

20:00 限时 20:00 [开始计时] [+5 分钟] [归零] [按未打完结算]

  • 开始计时 / 暂停 / 继续：随时停表、续表，已用时间会累计，暂停期间不走表；
  • +5 分钟：给这一场加时（可连点）；
  • 归零：已用时间清零、按当前全局限时重设，用于换场重开；
  • 按未打完结算：不等时间到，当场按当前大比分收场（裁判看错表、选手弃权时用）；
  • 结算后卡片状态显示「（计时器到点 · 未打完）」或「（未打完）」，并出现 撤销未打完，可退回继续打。

顶部工具条还有 全轮开始计时 / 全轮暂停：一次把所有未收场的桌子开表 / 停表。

到点结算的规则：

  1. 按当前大比分（含双败总决赛先计局）判定领先方获胜，平分时按上面的「到点时双方局数相同」处理；
  2. 计分走「记分规则 → 按大比分逐档设分 → 未打完」那张表（见 3.3.1）；
  3. 这场照常计入双方战绩（胜 / 负 / 平各 1 场）、赢局输局、累计小分，排名与晋级计算不受影响；
  4. 淘汰赛一定有人晋级：即使选了「记为平局」，淘汰类阶段也会改按种子号判定，避免对阵卡住；
  5. 关掉软件 / 关闭页面时，正在走的表会自动暂停（不会把离线这段时间算进去），下次打开点「继续」即可。

四、赛制

4.1 瑞士轮（swiss）

  • 按当前积分分层配对，同分相遇，尽量不与已交手过的人重复配对；
  • 人数为奇数时自动产生 1 个轮空；
  • 轮数一般取 log2(人数) 向上取整，如 8 人 3 轮、16 人 4 轮，也可自定。

每轮配对方式（设置 → 阶段设置 → 每轮配对方式）三选一：

方式行为适合
自动配对积分相近者优先，尽量避免重复交手常规瑞士轮，最省心
随机配对每轮在存活选手中重新抽签两两配对快棋赛、娱乐赛，弱化强弱分层
手动编排生成轮次时不自动配对，由你在「③ 对阵与录入」里点选配对现场喊桌、有特殊回避要求
  • 三种方式生成后、录成绩前都可以再手动微调（见第八章），不会锁死；
  • 随机配对同样遵守「不重复交手」与轮空规则，轮空人选按赛事的轮空规则判定。

平局判定为「双方都输」（可选，见 4.0）：瑞士轮要是允许平局，
「平局处理 + 本阶段平局判定」可以组合出「平局 = 双方各记一负」：两人都拿负场分、战绩表里
不出现「平」这一栏，相当于这场谁也没赢；小分仍按真实比分记录。

4.0 平局判定的三种口径（瑞士轮 / 循环赛 / 小组赛 / 双败淘汰通用）

阶段设置里有两项配合决定「打平了怎么算」：

「平局处理」「本阶段平局判定 → 任何平局都判为双方都输」结果
自动加赛决胜—平不了，必须打到分出胜负（加局）
允许平局不勾选（默认）算平局：双方各拿平局分，战绩各记一场「平」
允许平局勾选双方各计一负：各拿负场分，战绩表里没有「平」这一栏

勾选后适用于：

阶段类型勾选后的效果
瑞士轮 / 循环赛 / 小组赛（v1.11.2 起支持）平局双方各记一场负，积分按「负场分」算；胜/平/负战绩里不再出现平局；<br>提前晋级 / 提前淘汰、导出表、积分榜一律按「这场谁也没赢」处理
双败淘汰 / 小组赛·组内双败（v1.11.1 起支持）见 4.3：胜者组平局两人同掉败者组、败者组平局双双淘汰、总决赛平局由负场少者夺冠
勾选后小分不受影响：赢局 / 输局 / 净胜局 / 净小分 / 累进分仍按真实比分记录，
只有「积分 + 胜平负战绩」按双负计。
「平局处理」没选「允许平局」时，页面会提示本项届时才生效；
单败淘汰不提供该选项（平局会一直卡到加赛或改判）。

算法：轮数 = ceil(log2(人数 ÷ 晋级人数))，对阵表规模 = 2^轮数 × 晋级人数，
首轮轮空 = 规模 − 人数。阶段设置里会直接显示推算结果（「共 2 轮、首轮 12 人轮空、各轮实打场次 4 → 8」），
不用自己算，也不会出现「差一个人对不上」的半截对阵树。

  • 最后一阶段（没有下一阶段）自动按「留下 1 人（冠军）」规划；中间阶段按「晋级条件」里的人数规划；
  • 轮空直接并入下一轮：轮空者不占一场比赛，直接在下一轮以本人姓名出现，对阵图里一眼能看出谁轮空；
  • 「最多进行轮数」（默认 0）仍然保留：填了就以它为准，用于「先单败筛一轮再分组」的特殊玩法；
  • 可勾选「季军争夺战」，为半决赛负者加一场 3-4 名决赛（只在「打到冠军」时生效）；
  • 「④ 排名」页以完整树状对阵图展示，见 4.7。

首轮编排方式（阶段设置 →「首轮编排方式」）：

方式行为适合
按种子号编排（默认）标准种子位：1 号与末位同区，强手尽量分散，同分同段不会首轮相撞有明确种子的正式赛
分档抽签按种子顺序分成 N 档（默认 4 档），档内随机、档与档之间的强弱分布不变。2 档即「强档 vs 弱档」有实力分层但不想固定对手
完全随机抽签所有选手一起打乱现场抽签、娱乐赛、种子不全
  • 抽签在点「生成首轮对阵」时自动完成；首轮还没录成绩时，对阵图上方可点「重新抽签」再抽一次；
  • 一旦首轮有成绩就锁住抽签（想重抽可先「回退一步」）；
  • 抽签只改变谁碰谁，不改变轮空数量 —— 轮空仍由「人数 + 晋级人数」算出，20 人取 8 依旧是 32 位签表、12 人轮空；
  • 轮空的人不会因为是随机抽签就被换掉（v1.11.0 强化）：轮空位由上阶段排名靠前的选手占据， 抽签时这些位置完全不参与打乱，只在其余人之间重排。也就是说：即使选「完全随机抽签」或「分档抽签」， 谁轮空这个事实不会被改掉，排名靠前者的首轮免赛权始终保住；双败同理，只影响胜者组内部配对。
  • 双败淘汰同样支持这三种首轮编排方式，抽签只影响胜者组首轮配对。

4.3 双败淘汰（double_elim）

  • 分胜者组与败者组：胜者组输一场掉入败者组，败者组再输第二场才淘汰；每人最多输两场；
  • 起跑位置可自定义（v1.11.0 新增）：默认全员进胜者组。若想把上阶段的强手保护起来， 在阶段设置里填「双败 · 前 N 名直接进胜者组」即可 —— 填 4 表示本阶段名单里排名前 4 的选手直接排进胜者组， 其余人全部从败者组起步；填 0（默认）表示不分，全员进胜者组。
例子（16 人阶段）胜者组起步败者组起步
前 N 名 = 0（默认）16 人0 人
前 N 名 = 4前 4 名其余 12 人
前 N 名 = 8（一半）前 8 名后 8 名

胜者组首轮的场次数与轮空会自动重算，不需要手填；首轮编排方式（按种子 / 分档抽签 / 完全随机）
仍然照常生效，只作用在胜者组内部。

  • 平局判定为「双方都输」（可选，v1.11.1 起；完整口径见 4.0）：阶段设置 →「平局处理」下方勾选 「任何平局都判为双方都输」 后，本阶段出现的任何平局都不分胜负、双方各记一负：
平局发生在结果
胜者组两人一起掉进败者组（各第 1 负）
败者组两人各自吃到第 2 负，双双淘汰
总决赛胜者组冠军是第 1 负（掉进败者组），败者组冠军已是第 2 负当场淘汰；场上只剩一人 → 冠军由负场少的一方获得
  • 前提是平局处理选了「允许平局（平局即最终结果）」；若选的是「自动加赛决胜」，页面会提示本项届时才生效。
  • 对阵卡片上平局那桌会写 「平局 · 双方各记一负」 并标出去向；晋级路径也会写「负 → …」而不是「胜 → …」。
  • 不勾选（默认）：双败不允许平局，打成平局的场次会卡住本轮，直到改判或加赛为止（与以前一样）。
  • 「小组赛 + 组内双败」同样按这套规则处理。
  • 每轮生成时自动推进两条线，无需手工安排；对阵页分「胜者组 / 败者组」两块显示， 败者组按自己的顺序编号「败者组 第 N 轮」；
  • 必须先结算本轮：一轮成绩录完后点「结算本轮」（或直接点「生成下一轮」，系统会自动结算）， 两组归属才会推进；否则会拿旧状态重复生成同一轮；
  • 最后由胜者组冠军与败者组冠军打总决赛，规则三选一（阶段设置 →「双败淘汰 · 总决赛规则」）：
总决赛赛制含义场次
加赛制 reset（默认）胜者组冠军赢首场即夺冠；败者组冠军赢首场则双方各负一场，自动加赛一场定冠军1 或 2 场
无优势 none一场定胜负，胜者组冠军不享有额外优势，谁赢谁夺冠1 场
可升格决赛 elevate只打一场、比分累计不重置：先到原获胜局数者为胜；但若败者组冠军先到原获胜局数，目标立刻升格（默认原 + 1 局），双方带着原比分继续打；若胜者组冠军先到原获胜局数，则不升格、直接夺冠1 场
让局 handicap一方开局先计若干局，另一方需多赢同样局数才能夺冠；可选「胜者组冠军先计」或「败者组冠军先计」1 场
  • 让局的算法：先计 N 局相当于这 N 局已经赢了。例：总局制「先赢 3 局」+ 胜者组冠军先计 1 局， 该场最多打 4 局，胜者组冠军再赢 2 局即夺冠、败者组冠军仍需赢满 3 局； 对阵卡片与对阵图显示的是含先计局的总比分，并标注「先计 N 局」；
  • 总决赛独立局制：可只把总决赛设为 BO5（阶段内其余比赛仍为 BO3）；
  • 加赛局独立局制：加赛制下，加赛那一场可单独设局制，例如「总决赛首场 BO5、加赛 BO1」， 不勾选时沿用总决赛（或阶段）局制；
  • 可升格决赛怎么算（一场定胜负、比分累计，不是两场）： 以原局制 BO5（先赢 3 局）为例 ——
  • 第 1 局到第 N 局一路照常打，比分不清零；
  • 胜者组冠军先拿到 3 局 → 比赛立刻结束，胜者组冠军夺冠，不升格；
  • 败者组冠军先拿到 3 局 → 比赛不结束，目标自动升为 4 局（默认「原获胜局数 + 1」）， 双方带着原来的比分继续打，谁先到 4 局谁夺冠（最多打 7 局，即 BO7）；
  • 若比分打成 3:3，则第 7 局定胜负；
  • 升格后的目标局数可手动指定（必须大于原获胜局数，填小了会自动抬到「原 + 1」）；
  • 对阵图的总决赛卡片会标出「需 3 胜」→ 升格后变成「已升格 · 需 4 胜」，比分一直累计在同一格里。
  • 「④ 排名」页显示双败对阵图（胜者组一行 / 败者组一行），总决赛压在最右边、与胜者组同一行； 名次按对阵结果确定：最后一场总决赛的胜者为冠军、负者为亚军、 败者组决赛负者为季军，其余按被淘汰轮次倒序排列。

4.7 完整对阵图（怎么读）

「④ 排名」页的对阵图是开赛前就完整画出来的，每一格要么是选手姓名，要么写清「这一格是谁打上来的」：

  • 未定的格子用灰字斜体标出来源，例如 「第 1 轮 第 2 场胜者」「胜者组第 1 轮 第 3 场败者」「败者组第 2 轮 第 1 场胜者」「胜者组决赛胜者」；
  • 轮空者直接以姓名出现在下一轮，不会单独占一张「轮空」卡片；
  • 每张卡片三段：顶部是场次编号（如「胜者组半决赛 第 1 场」），中间两位选手（打过的显示比分，胜者黑底白字）， 底部两行是晋级路径：▲ 胜 → 下一场在哪，▼ 负 → 掉到哪（写「淘汰」「亚军」「夺冠」就是没有下一场了）；
  • 列头标注本轮人数与场次，如「本轮 20 人 · 4 场」；
  • 双败分两行：上面胜者组、下面败者组，总决赛与加赛局 / 升格决赛放在最右边、与胜者组同一行， 不再单独堆在最下面。

名次的判定规则（单败、双败通用）：先比「负场数」少的，再比「最后一次获胜的轮次」晚的，
最后比种子序。这样即使阶段被「最多进行轮数」提前掐断、根本没有决赛，
同一轮的胜者也一定排在负者之前 —— 不会出现「赢了却没晋级」。

4.8 多阶段合并对阵图（v1.11.0 新增）

赛事里只要有两个以上淘汰赛阶段（单败 / 双败都算），「④ 排名」页的对阵图上方就会出现切换条：

按钮作用
合并全部 N 个阶段（默认）把所有淘汰赛阶段横向接成一整条完整路径：第 1 阶段 → 第 2 阶段 → …… → 最终阶段
只看所选阶段回到原来的单阶段对阵图
打印合并对阵图把这条完整路径按一张图打印（自动横排、不拆页）
存 PDF直接导出 赛事名_淘汰赛合并对阵图.pdf

怎么读这张合并图：

  • 顶部一条说明棒写明「本图合并了哪几个阶段」以及当前总冠军（已经打完的话）；
  • 每个阶段是一个带编号的方块：方块头写明阶段名、赛制、人数、晋级目标是否已达成，右上角标「已结束 / 当前」；
  • 方块之间用箭头连接条衔接，写清「晋级 X 人进入下一阶段」，并列出实际晋级者的姓名，一眼看懂人是怎么一级一级上来的；
  • 每个阶段底部的 footer 写该阶段的冠军（最后一个阶段的 footer 同时也是总冠军）；
  • 瑞士轮 / 循环赛 / 小组赛等积分制阶段不会进合并图（它们不是淘汰树），但仍然会出现在阶段下拉里单独查看；
  • 阶段还没生成对阵时不进图；一个淘汰赛阶段都没有时会给出提示而不是报错。
手机上这张图会整块横向滑动，卡片的文字与间距不会被挤扁。

4.4 循环赛（round_robin）

  • 采用圆桌轮转法（Circle Method），保证每人与其他所有人都交手；
  • 「循环次数」设为 2 即为双循环（主客互换）；人数为奇数时每轮有 1 人轮空。
  • 允许平局时用不用「双方都输」见 4.0：勾选后全场平局者全部按各记一负处理。

4.5 小组赛（groups）

  • 把参赛者分成若干小组，组内可选择瑞士轮 / 单败 / 双败 / 循环赛任一赛制；
  • 分组方式三种：
  • 蛇形分组（默认）：按种子 1-2-3-4-4-3-2-1 蛇形分配，各组实力最均衡；
  • 随机抽签：完全随机打散；
  • 手动分组：自己把人拖到指定组。
  • 分组结果可在「对阵与录入」页的分组面板里随时调整：蛇形重排 / 随机重抽 / 逐人移组；
  • 组内赛制为瑞士轮 / 循环赛 / 双败时，都可勾选「本阶段平局判定 → 任何平局都判为双方都输」（见 4.0）， 勾选后组内排名的积分与胜平负战绩同步改写（组内双败则按 4.3 的掉组规则）。

小组赛 + 双败（v1.11.0 新增）

组内赛制选「双败」时，每个小组各自跑一套完整的双败流程：组内自己分胜者组 / 败者组、自己推进轮次、
自己打组内总决赛，组与组之间互不干扰。用法：

  • 各组的双败状态机独立，同轮次里 A 组可能还在胜者组首轮、B 组已进入败者组第 2 轮，系统分别生成、分别结算；
  • 「前 N 名直接进胜者组」在小组赛里按组内成员的上阶段排名/种子序计算（填 0 表示组内全员胜者组起步）；
  • 每组全部打完才判定该组结束，所有小组都结束后本阶段才算结束，之后照常按「晋级条件」把人送进下一阶段；
  • 小组名次要到组内总决赛打完才确定，中途显示为进行中，不会提前把某人列为小组第一。

4.6 提前晋级 / 提前淘汰（swiss / round_robin / groups）

阶段设置里勾选「启用自动判定」，按战绩实时裁人：达到 N 胜立即锁定下一阶段席位、本阶段不再出场；达到 N 负立即出局。每轮成绩录完后自动判定。

配置项含义
判定依据按比赛场次（大比分）：赢 3 场即晋级、输 3 场即淘汰；按小局：累计赢 6 局即晋级、输 6 局即淘汰（轮空不计局）
达到几胜 → 提前晋级0 = 不设；3 = 拿到第 3 胜时锁定名额
达到几负 → 提前淘汰0 = 不设；3 = 吃到第 3 负时出局
提前晋级者下一阶段加分进入下一阶段时直接计入积分，不改选手全局初始分
每提前一轮额外加分5 轮制里第 3 轮锁定 → 提前 2 轮 → 额外 +2×该值
  • 排名：提前晋级者整体排在未定者之前（越早锁定越靠前）；提前淘汰者整体排最后（越晚出局越靠前）；名次不跨层并列；
  • 区分提前与末轮达标：最后一轮才达到线的显示「晋级（末轮达标）」/「淘汰（末轮出局）」，不加分；
  • 对手分照样会变：不出赛但仍留在排行榜，对手分按对手实时积分重算；本人积分与场次不再增加；
  • 晋级保证：提前晋级者无论「按人数 / 按积分线 / 全部晋级」都会进入下一阶段；已淘汰者即使「全部晋级」也不会被带进去；
  • 阶段提前收尾：剩余未定者不足 2 人时本阶段自动结束；
  • 与「中途淘汰（按名次裁人）」的区别：前者看战绩，后者看名次，两者可同时启用；
  • 仅对积分制阶段生效（单败 / 双败本身即输够场次出局）。

五、多阶段赛程

一个赛事可以串起任意多个阶段，每阶段独立设置：

  • 赛制与轮数：如「小组赛 3 轮 → 单败淘汰 8 强」；
  • 晋级条件：
  • 按人数：取前 N 名晋级（小组赛可选「每组前 N 名」）；
  • 固定人数 + 同分同名次：先取满 N 人，若第 N 名有同分者，同分的人一起晋级（最终可能多于 N 人）。 例：取前 2 名，而第 2、3 名同分 → 两人都进；取前 2 名而第 2~5 名四人同分 → 5 人全进；
  • 按分数：达到指定分数线者晋级；
  • 全部晋级（仅做阶段划分）。

淘汰赛阶段按名次裁人时不做同分扩招（对阵结果本身就能分出先后），避免把已淘汰的人又捞回来。

  • 分数继承：勾选后可把上一阶段的积分按比例（如 100%、50%）带入本阶段，0% 即完全清零重开；
  • 下面的「同时继承小分」勾选后，上一阶段的全部小分都按同一个比例折算带入： 累计小分、净小分、赢局、输局、净胜局、对手分、累进分（默认不勾 = 只带积分，小分从 0 重新算）；
  • 带进来的小分是本阶段的起点，本阶段打出的成绩继续往上累加，破同分时直接生效；
  • 例：上阶段累计小分 20、比例 50% → 本阶段开门就带 10 分小分，第一局赢下 2 分后显示 12；
  • 净小分按「本阶段小分 − 本阶段对手小分」计算后再叠加继承值，所以双方都继承也不会互相抵消；
  • 名次表在继承开启时多一列「继承分」；小分继承静默生效，排名页不再额外提示。
  • 中途淘汰：两种方式可叠加 —— ① 按战绩（达 N 胜提前晋级 / 达 N 负提前淘汰，见 4.6）；② 按名次：第 N 轮后只保留前 M 名；
  • 阶段独立的局制与记分：每个阶段可打开「本阶段局制与记分」开关，单独设局数、胜负条件与计分模式， 例如小组赛用「一局定胜负 / 胜 3 分」，淘汰赛用「五局三胜 / 按赢局计分」。 未打开开关的阶段沿用赛事级别的默认值。赛程流水线上会标注「独立局制 / 独立记分」。

阶段跑完点「结束本阶段并晋级」，系统按晋级条件结算并自动进入下一阶段。

六、选手管理

  • 批量导入：一行一个名字，也支持逗号、分号、制表符分隔；从文件导入支持 .txt / .csv；
  • 字段：姓名、种子序号（决定初始排位与轮空优先）、初始携带分、备注；
  • 退赛 / 取消资格：在选手列表点「退赛」，会弹出页内输入框填写原因（默认「退赛」，直接回车即可）， 确认后立即生效：立刻退出所有还没打完的比赛（判给对手「不战而胜」，提示里会写明结算了几场）， 之后再也不会被排进任何新的对阵（瑞士轮 / 循环赛 / 单败 / 双败都一样：双败还会把他从胜者组、败者组、 待注入名单里一并剔除；轮空人数会自动重算），排名表状态列标注「退赛 / 取消资格」，已完成的成绩保留； 对阵图里退赛者的名字会加删除线并挂「退赛」标签，不会再被误认为在赛。 点「恢复」可撤回参赛状态（已经判给对手的那局不会自动改回，需手动调整）； 所有确认框都是页面内的，不依赖系统弹窗，桌面端与手机端表现一致。
  • 支持临时停用（active）而不删除，方便误操作回滚。

七、对阵与录入

每一桌显示为一张卡片（横向一行）：桌号、双方、当前比分、胜负状态。

每位选手名下有一行实时战绩：3 胜 1 负 0 平 · 6 分 · 第 2 名，分别是本阶段的胜 / 负 / 平场次、本阶段积分、当前名次，末尾还会标注「已提前晋级 / 已淘汰 / 退赛」。它随录入即时刷新，不用等「完成本轮」。

  • 进行中的比赛只更新比分（如 1 : 0），分出胜负后才计入战绩与积分；
  • 回看历史轮次时显示「截至该轮结束」的战绩；
  • 淘汰赛还会在卡片上标出晋级路径（见 7.1）。
  • 直接填比分：在「直接填比分」的 [ ] : [ ] 里填双方赢局数（如 2 : 1），按回车或点「结算」即完成本场， 系统自动判胜负并按当前记分规则给分，旁边实时显示「胜 +3 / 负 +0」；
  • 逐局录入：卡片下方的「A 胜 / B 胜 / 平局」按局记录，适合需要留痕的场合；
  • 改判：重新填一次比分即覆盖；也可点「撤销上局」逐局回退；
  • 计时 / 提前收场：开启计时器后，卡片上有倒计时与 开始计时 / 暂停 / +5 分钟 / 归零； 比赛打不完时点 按未打完结算（或等计时器到点自动结算），按当前比分收场并按「未打完」档位计分， 事后可点 撤销未打完 退回继续打（详见 3.6）；
  • 越界校验：单方赢局不超过「赢多少局获胜」、总局数不超过「每场局数」，打满模式要求正好打满。

启用计时器后还会多出 全轮开始计时 / 全轮暂停。
有多个阶段时，「③ 对阵与录入」与「④ 排名」页都会多出 查看合并对阵图 入口（见 4.8）。

回退一步：撤销最近一次操作（生成轮次、完成本轮、结束阶段等），数据回到上一步，用于改错。

7.0 随时切回之前的阶段与轮次（v1.11.0 新增）

页面顶部有两排小按钮（chips），不需要「先点历史再翻」：

  • 第一排是阶段：多阶段赛事才会显示，按钮上标注「已结束 / 当前」，点了就跳到那个阶段查看；
  • 第二排是轮次（如 第 1 轮 第 2 轮 第 3 轮），点了立刻显示该轮的原始对阵与比分；
  • 右侧有 回到最新轮 / 回到当前阶段 一键返回；已经在最新位置时按钮会置灰。

三种情况下的行为不一样，请注意：

切到能否改成绩说明
当前阶段 + 最新一轮✅ 正常录入平时的工作界面
当前阶段 + 历史轮次✅ 可以补录 / 改判发现前面某桌比分写错时直接改，改完仍停在这一轮，不会把你甩回最新轮
已经结束的旧阶段❌ 只读卡片下方不出现任何录入按钮，页面给出「只读」提示；本轮的按钮也不带「· 当前」标记
取消资格判定、晋级推算、排名快照都以最新一轮为准，回改历史轮次后排名会自动重算。

7.1 淘汰赛的晋级路径

单败 / 双败阶段，每张卡片在选手下方多一行 胜者 → …、负者 → …，直接写明这场的胜者、负者接下来打哪一场：

  • 胜 → 半决赛 第 1 场 / 负 → 败者组第 2 轮 第 1 场（双败：胜者组输一场掉进败者组）；
  • 负 → 淘汰 表示本阶段结束；胜 → 夺冠（无后续比赛） 表示这是最后一场；
  • 胜 → 下一轮（待生成） 表示下一轮还没排，点「生成下一轮」后变成具体场次；
  • 双败加赛制下，首场总决赛显示 胜 → 总决赛 · 加赛局 第 1 场。

「④ 排名」页的对阵图同样标注路径并给每场编号（如「半决赛 第 1 场」）；还没打到的轮次会显示为「待定」占位卡，因此任何时候看到的都是完整对阵树。

八、手动编排与随机抽签

8.1 点选式编排（瑞士轮 / 循环赛、小组赛）

点「手动编排 / 随机抽签」打开编排面板（仅对当前最后一轮且尚未有成绩的轮次开放）：

  • 点选配对：面板上方列出本轮可出赛的所有选手（带当前积分）， 点第一个名字 → 点第二个名字，两人就组成一桌；再点一下已选中的名字可取消选择；
  • 一键批量：「随机配对」把剩下的人一次排满；「按积分自动配」按积分相近原则排； 「清空重来」把草稿清空；
  • 轮空：人数为奇数时必须点一名选手设为轮空（面板会明确提示），否则不允许确认；
  • 确认本轮对阵：确认后才真正生成本轮；没录成绩前还能再进来改；
  • 拆开 / 逐桌微调：已排的桌可点「拆开」重排；下拉式「逐桌微调」仍保留在面板底部，适合精确替换；
  • 若把「每轮配对方式」设为手动编排，点「生成首轮对阵」会直接打开这个面板，而不是自动配对。

校验会挡住这些情况：漏排选手、同一人被排两次、奇数人却没指定轮空、上一轮还没打完。

8.2 淘汰赛抽签

淘汰赛的首轮不由这层面板编排，而是用设置里的「首轮编排方式」（按种子 / 分档抽签 / 完全随机），
见 4.2。生成后、开打前可在对阵图上方点「重新抽签」换一次结果。

适合「既定规则配对后，还想人工微调或现场重新抽签」的场景。

九、排名

  • 积分制阶段（瑞士轮 / 循环赛 / 小组赛）：显示名次、选手、积分、场次、胜 / 平 / 负、赢局-输局、 净胜局、累计小分、净小分、累进分、上阶段分、对手分、状态（后几列按启用的破同依据显示）；
  • 淘汰制阶段（单败 / 双败）：有两个以上淘汰赛阶段时，默认显示合并对阵图（见 4.8）， 可切到「只看所选阶段」看单阶段的树状图；每张卡片标注场次编号与胜者 / 负者的下一场， 再显示按对阵结果排出的名次表，冠军行反白，冠亚季军直接标在「结果」列；
  • 阶段没打完时名次是临时的：结果列显示「待定（争冠中）」「待定（争季军）」，表头上方给出提示，不会把还没打的决赛提前判成冠军；
  • 并列名次：完全同分同对手分时显示相同名次（如两个第 3 名，下一名跳为第 5 名）；
  • 轮空按胜场计：轮空者的「场次」与「胜」都会 +1，另在导出表里单列轮空次数；
  • 分阶段查看：顶部下拉选择阶段；小组赛可分别查看各组与总排名；
  • 手动调序：右侧「上 / 下」按钮即时调整名次，按排名依据里的「手动名次」优先级生效；
  • 可按「打印排名」输出纸质表或存为 PDF。

十二、常见问题

Q：双击 exe 没反应 / 一闪而过？
A：确认解压完整（resources、locales 等 dll 和 exe 必须在同一目录）。若被杀毒软件拦截，加白名单后重试。

Q：进度条显示「本轮未完成」，但所有人都打了？
A：多半有一桌没录比分，或有人被上下两边同时占用。看卡片上是否有空桌（可在编排面板删除空桌）。

Q：填了 2:2 提示不对？
A：三局两胜不可能打成 2:2。单方赢局不能超过「赢多少局获胜」，总局数不能超过「每场局数」。
若确实要允许平局，把平局处理改成「允许平局」，并确保总比分相等且已打满。

Q：中途有人退赛，后面的对阵怎么办？
A：在「选手管理」里标为退赛即可。标的那一刻：他还没打完的场次会立刻判给对手（不战而胜，提示框会告诉你结算了几场）；
之后：生成轮次时不会再把他配进去，双败会同时把他从胜者组 / 败者组名单里剔除，轮空人数自动重算；
已完成的成绩保留（事后退赛不改写历史），排名表和对阵图都会标注「退赛」（对阵图里名字带删除线 + 标签）。
「恢复」只恢复参赛状态，已经判给对手的那场需要手动改回来。

Q：能不能不改赛制，只改某一阶段的胜负分？
A：可以。在该阶段勾选「本阶段记分」，单独设分值即可，不影响其他阶段。

Q：数据会丢吗？
A：本地存储随系统清理浏览器数据、卸载应用、清除应用数据而丢失。请定期导出 JSON 存档。
